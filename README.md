# 👁️ Reconocimiento Facial Unity

Aplicación desarrollada durante mis prácticas curriculares utilizando Unity y C#.

## Tecnologías

- Unity
- C#
- OpenCV for Unity

## Funcionalidades principales

- Detección de rostros
- Comparación facial
- Procesamiento de imágenes
- Captura mediante cámara

## Contexto

Proyecto desarrollado durante mis prácticas curriculares en empresa como estudiante de Ingeniería Multimedia.

## Aprendizajes

Este proyecto me permitió adquirir experiencia trabajando con visión artificial, procesamiento de imágenes y aplicaciones desarrolladas con Unity.
